# 🐍 Snake Game - Node.js Console

A simple Snake Game built using Node.js in the terminal/console. <br><br>
<img width="400" height="270" alt="Recording 2026-05-13 010334 (1)" src="https://github.com/user-attachments/assets/70ce9a3f-37bf-4883-9940-de359dfde3c1" />

## Features

- Draws the game board in the terminal
- Snake movement using arrow keys
- Random food spawning
- Food respawns every 5 seconds
- Score increases over time
- Score bonus when eating food
- Snake speed increases after eating food
- Collision detection
- Game Over screen
- Saves scores to `scores.txt`
- Colored terminal UI using Chalk

---

## Technologies Used

- Node.js
- Chalk
- Readline
- File System (`fs`)

---

## Install Dependencies

```bash
npm install
```

This will install all required packages.

---

## Run the Game

```bash
node snake.js
```
